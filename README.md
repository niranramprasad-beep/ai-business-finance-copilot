# AI Business & Finance Copilot

Smartsoft summer internship project — 6-week build.

## What's in here

- `apple_stock.py` — Day 1: pull Apple's stock history with yfinance and plot it
- `nike_challenge.py` — Day 2: find Nike's highest closing price this year
- `superstore_analysis.py` — Day 2: total revenue, top 5 products, revenue by region (needs the Kaggle Superstore CSV in this folder)
- `.env` — API keys (never committed, listed in .gitignore)

## Setup

```
pip3 install jupyter pandas numpy matplotlib plotly streamlit scikit-learn yfinance openpyxl python-dotenv
pip3 install groq google-generativeai langchain langchain-groq
```

## Run anything

```
python3 filename.py
```
